# QIP Framework: Hybrid Quantum-Classical Image Processing

[![PyPI version](https://img.shields.io/pypi/v/qip-framework.svg)](https://pypi.org/project/qip-framework/)
[![License: MIT](https://img.shields.io/badge/License-MIT-yellow.svg)](https://opensource.org/licenses/MIT)
[![Python Version](https://img.shields.io/badge/python-3.8%2B-blue.svg)](https://www.python.org/)

**QIP Framework** is a modular, research-oriented library designed for investigating Quantum Image Processing (QIP) algorithms under realistic **NISQ (Noisy Intermediate-Scale Quantum)** constraints. It provides a high-level API to encode classical images into quantum states, apply quantum transforms, and simulate results with hardware-aware noise models.

---

## 🛠️ Key Features
- **Flexible Encoding**: Optimized implementations of **FRQI** (Flexible Representation of Quantum Images) and **QPIE** (Quantum Probability Image Encoding).
- **Advanced Algorithms**: 
  - **QHED**: Quantum Hadamard Edge Detection for gradient extraction.
  - **Quantum Transforms**: Parametric brightness adjustment and image inversion.
- **Hardware-Aware Simulation**: Integrated noise models including **Thermal Relaxation (T1/T2)**, depolarizing errors, and measurement readout errors.
- **Scientific Benchmarking**: Automated comparison tools against classical baselines (Sobel, Canny) using **SSIM** and **Cosine Similarity**.
- **Ablation Studies**: Built-in support for disabling noise or entanglement to isolate algorithmic performance.

## 🎯 Quick Start (Example Usage)
The `QIPPipeline` class simplifies the entire research workflow into a few lines of code:

```python
from qip_framework.pipeline import QIPPipeline

# 1. Initialize a research pipeline with noise simulation
pipeline = QIPPipeline(encoding="qpie", algorithm="qhed")

# 2. Run the experiment on an image
results = pipeline.run("data/test.png", shots=8192)

# 3. Access scientific metrics
print(f"CNOT Count:      {results['cnot_count']}")
print(f"Transpiled Depth: {results['transpiled_depth']}")
print(f"SSIM Score:      {results['ssim']:.4f}")
```
